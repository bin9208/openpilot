# 네이버 지도 6.8.0.5 단일 TEST APK

공개 정식판이 아닙니다. Android 11 이상 arm64 기기를 대상으로 하며 모든 기기
호환성을 보장하지 않습니다. c3는 `codex/naver-support-20260924`를 사용합니다.
현재 설치·실주행 검증은 하지 않았습니다. 운전자는 항상 직접 제어할 준비가
되어 있어야 하며 감속이 되리라 기대하고 방지턱·카메라에 접근하지 마세요.

## 지원 범위와 미검증 항목

- Tmap과 Naver 중 하나로 길안내를 시작해 선택합니다. 공통 제어기를 사용합니다.
- 안내 세션, 기본 TBT, 현재 카메라·방지턱, 경로 좌표 입력을 지원하는 테스트 코드입니다.
- 카메라 통과 후 해제, 네이버 방지턱·곡선로 감속, 가속페달 속도 유지의 실제 주행은 재검증해야 합니다.
- 지원 차량의 HDA 후보로 폴백합니다. HDA에 없는 방지턱 정보가 생기는 것은 아닙니다.
- 차선·목적지/ETA·전체 교차로 종류·신호등 등의 Tmap 수준 전체 매핑은 미완료입니다.
- 기존 화면에서 NAVER/TMAP은 안내 출처, N/T/HDA 접두사는 감속 출처입니다.
- 안내 종료 뒤 새 경로가 수신되지 않으면 앱 재실행 후 새 안내를 시작하세요.

## 설치 전

서명이 현재 설치 앱과 다르면 덮어설치가 거부됩니다. 이 작업은 폰에 설치하지
않았고 기존 앱·데이터를 삭제하지 않았습니다. 거부되면 먼저 앱 데이터와 진단
DB 보존 방법을 확인하세요. 무조건 삭제·재설치하지 마세요. provenance.json에
서명 지문과 코드 커밋, SHA256SUMS.txt에 APK 해시가 기록됩니다.

## 오프라인 기록과 테스트

field 기록기는 앱 내부 SQLite에 저장하도록 구성되어 PC/ADB 연결이 필요하지
않습니다. 최대 64 MiB 제한과 채널별 보존 한도가 있어 모든 프레임 보존은
보장하지 않습니다. 새 APK의 실기기 오프라인 저장은 아직 검증 전입니다.
기록에는 제한된 상태·타입·건수·매핑 결과가 들어가며 원본 경로 좌표·목적지는
기록하지 않습니다. DB와 로그를 공개 이슈에 올리지 마세요.

정차 상태에서 안내를 시작하고 연결 상태를 확인한 뒤 ADB/PC 없이 주행하세요.
조작·관찰은 동승자가 하거나 정차 후 수행하세요. 방지턱 전후, 카메라 통과 전후,
곡선로와 가속페달 개입, 네이버 종료 후 HDA, Tmap 전환을 확인합니다. 문제가
생기면 안전하게 직접 제어하고 발생 시각·표시를 기록해 주세요. 이후 한 기기만
연결해 `naver_patch.py extract-capture --profile 6.8.0.5 --output-root <새 D 폴더> --json`
으로 추출합니다. 앱 삭제나 데이터 초기화 전에는 반드시 캡처를 보존하세요.
